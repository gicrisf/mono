## Overview

The theme treats each page as a printed sheet. A neutral desk surrounds a paper surface, dotted rules separate sections, and hard shadows mark interactive controls.

## Documentation First

The documentation layout adds a grouped sidebar, a sticky outline, breadcrumbs, and previous and next links that cross section boundaries.

## Blog Ready

The same shell supports a blog list and article pages. Pagination, dates, tags, and categories remain optional.

## Search

Zola's search index is styled as a small catalog panel and opens from the navigation or the keyboard.
